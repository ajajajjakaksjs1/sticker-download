# Telegram Sticker Download Bot

Telegram бот для скачивания и конвертации стикеров с поддержкой различных форматов.

## Возможности

- 🔐 **Админ-доступ**: Только авторизованные пользователи могут использовать бота
- 📱 **Одиночные стикеры**: Автоматическое извлечение всех форматов из стикера
- 📦 **Стикерпаки**: Скачивание целых наборов стикеров с подтверждением
- 🎨 **Форматы**: PNG, JPG, WEBP, GIF с сохранением прозрачности
- 📁 **Архивация**: Автоматическое создание ZIP-архивов
- 📊 **Логирование**: Подробные логи всех операций

## Поддерживаемые форматы

- **PNG** - с прозрачностью
- **JPG** - с белым фоном
- **WEBP** - оригинальный формат Telegram
- **GIF** - для анимированных стикеров
- **TGS** - анимированные стикеры Telegram (требует дополнительные инструменты)

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ajajajjakaksjs1/sticker-download.git
cd sticker-download
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env`:
```env
BOT_TOKEN=your_bot_token_here
ADMIN_ID=your_telegram_user_id
```

4. Соберите проект:
```bash
npm run build
```

5. Запустите бота:
```bash
npm start
```

## Использование

### Команды

- `/start` - Проверка доступа и приветствие

### Функции

1. **Отправьте стикер** - бот автоматически:
   - Извлечет все доступные форматы
   - Сконвертирует в PNG, JPG, WEBP, GIF
   - Создаст ZIP-архив
   - Отправит результат

2. **Отправьте ссылку на стикерпак** (например: `https://t.me/addstickers/UtyaDuck`):
   - Бот запросит подтверждение
   - При согласии скачает все стикеры из пака
   - Сконвертирует каждый стикер
   - Создаст архив с папками по форматам

## Структура проекта

```
src/
├── config.ts              # Конфигурация
├── main.ts                 # Точка входа
├── types/                  # TypeScript типы
├── services/               # Основные сервисы
│   ├── telegramService.ts  # Работа с Telegram API
│   └── converterService.ts # Конвертация изображений
├── handlers/               # Обработчики событий
│   ├── adminHandler.ts     # Админ-функции
│   └── stickerHandler.ts   # Обработка стикеров
└── utils/                  # Утилиты
    ├── logger.ts           # Логирование
    └── fileUtils.ts        # Работа с файлами
```

## Конфигурация

Основные настройки в `src/config.ts`:

- `BOT_TOKEN` - токен Telegram бота
- `ADMIN_ID` - ID администратора
- `TEMP_PATH` - папка для временных файлов
- `RESULT_PATH` - папка для результатов

## Логирование

Логи сохраняются в:
- `logs/app.log` - основные логи
- `logs/error.log` - ошибки
- Консоль - для отладки

## Запуск в продакшене

1. Соберите проект:
```bash
npm run build
```

2. Запустите в фоновом режиме:
```bash
nohup npm start > bot.log 2>&1 &
```

3. Проверьте статус:
```bash
ps aux | grep node
tail -f bot.log
```
