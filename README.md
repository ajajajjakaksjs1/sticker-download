# Telegram Sticker Download Bot

Python-based Telegram bot для скачивания и конвертации стикеров в различные форматы (PNG, JPG, WEBP, GIF).

## Возможности

- 🎯 **Минималистичный интерфейс** - простота и удобство использования
- 🔒 **Проверка админа** - доступ только для авторизованных пользователей
- 📦 **Одиночные стикеры** - автоматическая конвертация в PNG, JPG, WEBP, GIF
- 🎨 **Стикерпаки** - скачивание всех стикеров из пака с подтверждением
- 🎭 **Поддержка всех форматов**:
  - TGS (Lottie анимации) → PNG, JPG, WEBP, GIF
  - WEBM (видео стикеры) → PNG, JPG, WEBP, GIF  
  - WEBP/PNG (статичные) → PNG, JPG, WEBP
- 🌟 **Прозрачность** - сохранение прозрачного фона как в оригинальных стикерах
- 📁 **Архивация** - автоматическое создание ZIP архива с папками по форматам
- 📊 **Логирование** - подробные логи всех операций

## Установка

### Требования

- Python 3.8+
- FFmpeg
- ImageMagick

### Установка зависимостей

```bash
# Системные зависимости (Ubuntu/Debian)
sudo apt-get update
sudo apt-get install -y ffmpeg imagemagick

# Python зависимости
pip install -r requirements.txt
```

### Настройка

1. Создайте файл `.env`:
```env
BOT_TOKEN=your_bot_token_here
ADMIN_ID=your_telegram_user_id
```

2. Получите токен бота у [@BotFather](https://t.me/BotFather)
3. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot)

## Запуск

### Обычный запуск
```bash
python main.py
```


## Использование

### Команды

- `/start` - Запуск бота (только для админа)

### Отправка стикера

1. Отправьте любой стикер боту
2. Бот ответит "📁 Идет сохранение."
3. После обработки получите ZIP архив с папками:
   - `png/` - PNG с прозрачностью
   - `jpg/` - JPG с белым фоном
   - `webp/` - WEBP формат
   - `gif/` - GIF анимация (для анимированных стикеров)

### Скачивание стикерпака

1. Отправьте ссылку на стикерпак: `https://t.me/addstickers/PackName`
2. Бот спросит подтверждение: "*️⃣ действительно хотите, чтобы я скачал все что имеется из этого пака?"
3. Нажмите "Да" для скачивания или "Нет" для отмены
4. При подтверждении бот скачает все стикеры из пака и отправит архив

## Технические детали

### Поддерживаемые форматы входных стикеров

- **TGS** - Lottie анимации (JSON в gzip)
- **WEBM** - Видео стикеры
- **WEBP** - Статичные стикеры
- **PNG** - Статичные стикеры

### Выходные форматы

- **PNG** - С прозрачным фоном
- **JPG** - С белым фоном, качество 95%
- **WEBP** - С прозрачностью, качество 95%
- **GIF** - Анимация для TGS/WEBM стикеров

### Библиотеки

- **aiogram 3.20.0** - Telegram Bot API
- **Pillow** - Обработка изображений
- **rlottie-python** - Рендеринг Lottie анимаций
- **FFmpeg** - Конвертация видео
- **ImageMagick** - Создание GIF анимаций

## Логирование

Все действия логируются в файл `bot.log`:
- Команды пользователей
- Процесс конвертации
- Ошибки и предупреждения
- Статистика обработки

- Очистка временных файлов после обработки
- Логирование всех попыток доступа
